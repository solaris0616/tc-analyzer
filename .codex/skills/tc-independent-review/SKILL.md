# tc-analyzer independent review

`.codex/instructions/independent-review.md`を読む。

自分がすでに`independent_reviewer`または独立レビュー担当として起動されている場合は、新しいエージェントを起動せず、自分で監査を実行する。それ以外の場合は、新しい`independent_reviewer`を起動する。利用できない場合は、新しい汎用サブエージェントへ同じ基準と「編集禁止」を明示する。

レビュー依頼には次を含める。

- ユーザー要求と受け入れ条件
- 対象工程（設計、実装、テスト、最終）
- 対象ファイルまたは差分
- 実行済み検証と未確認事項

修正案や親エージェントの結論を先に教えてレビューを誘導しない。指摘を受け取ったら根拠を確認し、妥当なものだけを修正する。修正後は同じエージェントを再利用せず、別の新しいレビュー担当に解消確認を依頼する。
